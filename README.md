# 扫码器（Saoma Scanner）

吐槽：仓库来了100台货需要入库，这么简单的一个软件，结果保存就要买会员什么鬼，自己做。30分钟搞定，主打一个轻巧免费好用。

一个极简的安卓条形码扫描工具。**只扫一维条码**，多码时红框点选，离线识别，结果可导出 CSV。
为仓库盘点、快递录入这类"要连着扫很多个"的场景做的。

![界面](docs/screenshot.png)

## 下载安装

到 [Releases](../../releases) 下载 `saoma-scanner-v1.8.apk`，传到手机点击安装（提示"未知来源"允许即可）。
首次打开同意相机权限就能用。

- 系统要求：Android 5.0（API 21）及以上，需要后置摄像头
- 识别模型已内置，**完全离线，不联网**
- 安装包约 5.9 MB（versionCode 9 / versionName 1.8），只包含 arm64-v8a / armeabi-v7a

## 功能

- 上半部分是摄像头取景框，右上角有 **开灯/关灯** 按钮（手机闪光灯补光）。只识别一维条形码
  （Code128 / Code39 / Code93 / Codabar / EAN-13 / EAN-8 / ITF / UPC-A / UPC-E），**不认二维码**。
- 取景框里只有 1 个条码：绿色框，识别稳定约 0.55 秒后**自动记录**。
- 取景框里同时有多个条码：按「优先」策略自动选一个（绿框标"自动"，1 秒后记录），或用「范围」限定只认某一个；也可直接手动点红框。
- 「去重」开关（默认开）：同一个条码只记录一次。按「去掉前导 0」归一化，所以同一个 UPC-A
  被识别成 12 位或带 0 的 13 位也不会重复。要扫同一款商品的多个条码时，把它关掉。
- 「提示」按钮循环切换记录成功时的反馈：**无 / 声音 / 声音+震动 / 震动**（默认声音+震动，会记住选择）。
- 「优先」按钮——**同屏出现多个条码时**怎么选（循环切换，记住选择）：
  - **智能**（默认）：记住你上次记录/点选的那种条码（编码格式 + 长度），下一箱同屏出现同一种时
    **自动记它**（绿框 + 标注"自动"，约 1 秒判定）；其他码仍是红框，随时可改点，改点后重新学习。
  - **优先：商品条码 / 优先：Code128**：固定只自动记这种格式的码。
  - **优先：手动**：多码时全部手动点选（最先的行为）。
  - 判定不唯一时**不猜**，退回手动点；但会优先挑「和上次记录的值前缀最像」的那个。
- 同屏多码自动判定的等待时间是 **1 秒**（留出人工干预时间）；画面里只有 1 个条码时仍是约 **0.55 秒**即记。
- 「范围」按钮——**限定只识别画面里的一小块**（循环切换，记住选择；长按恢复默认位置）：
  - **范围：全部**：画面里所有条码都参与（默认）。
  - **范围：取景框**：只识别**落在框内**的条码。框外用暗色压暗；框体可拖动、拉四角缩放，适配要扫的那个条码。
  - **范围：扫描线**：屏幕中间一条红线，**只有压到线上的条码**才被识别；线可上下拖动。相当于扫码枪的激光线，对准只在上下一个方向，最快。
  - 范围之外的条码会画一个**细灰框**提示"这儿有码但忽略了"，绝不会被记录。顶部也会提示"把条码放进框里 / 对准红线"。
- **重复的条码**：不会重复记录，并且给一个**和"记录成功"不同的提示**（不同的"嘀"声 + 两声短震），
  顶部提示条同时变**红色**提醒"已经记录过啦"，不用反复扫。
- 「撤回」删除最后一条；「清除」清空全部（二次确认；清空后还停留在画面里的条码不会马上又被记回来）。
- 中间是文本框：扫描结果一行一条，可以直接手动编辑、删除。**结果会自动保存**，
  切到别的界面、存 CSV、甚至被系统回收后重新打开都不会丢。
- 「保存为 CSV」：导出一份 csv 文件（UTF-8 带 BOM，一行一条，Excel 直接打开不乱码）。
- 「复制到剪贴板」：把所有记录复制到剪贴板。

## 现场使用提示（仓库/盘点场景）

- **扫同一款商品、要记多条**：先点一下「**去重：开**」变成「**去重：关**」，否则同一个条码只会记一条。
  只想记录"有哪些不同的条码"时保持「去重：开」。
- **环境嘈杂**：点「提示」切成「**震动**」（或「声音+震动」），靠手感确认，不用看屏幕。
- **别急着动**：画面里只出现 1 个条码时约 0.55 秒自动记一条，并"嘀"一声；听到"嘟嘟"两声 + 红条，
  说明**这个条码已经记过了**，不用再扫。
- **多个条码同时在画面里**：摸清楚是哪一种码要点时——**第一次点一下**你想要的（比如"商品条码"），
  之后「优先：智能」会记住这种码，同款箱子再扫就**自动记它**（绿框标"自动"，1 秒后记录），
  不用每箱都点；换另一种码再点一次即可。只想自动记固定一种，就把「优先」切到"商品条码"或"Code128"。
- **箱贴上码多、想稳稳只扫某一个**：用「范围」按钮。
  - 最省事是 **范围：扫描线**：把红线压到要扫的那个条码上，压线就记；线可上下拖到顺手的位置。
  - 如果两个码在同一高度并排（一条线会同时压到），用 **范围：取景框**：拉框只罩住要扫的那个。
  - 范围和「优先」可以叠加：框/线里若有多个码，仍按「优先」策略选。
- 记录会**自动保存**，中途退出、接电话、切应用都不会丢；回来接着扫即可。

## 自己编译

需要自备工具链：**JDK 17 + Android SDK 34（build-tools 34.0.0）+ Gradle 8.7**。

```
gradle assembleRelease
```

- 本仓库**不含签名文件**：请在 `keystore/` 下自建一个 keystore，并修改 `app/build.gradle`
  里 `signingConfigs.release` 的路径与密码（`keystore/` 与 `local.properties` 已被 .gitignore 忽略）。
- `local.properties` 需要写自己的 SDK 路径，例如：`sdk.dir=C\:\\Android\\Sdk`
- 应用图标（`app/src/main/res/mipmap-*/ic_launcher.png`）与提示音（`app/src/main/res/raw/*.wav`）已提交，
  一般不用重新生成；要改的话跑 `scripts/make-beeps.ps1` / `scripts/make-icons.ps1`（需 PowerShell，脚本仅 ASCII/BOM 安全）。


## 技术栈

- **CameraX** 1.3.4 —— 相机预览 + 分析流
- **ML Kit** barcode-scanning 17.3.0（bundled，离线）—— 一维条码识别
- 纯 Java + 框架控件，无 AppCompat；R8 混淆后 5.8 MB
